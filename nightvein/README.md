# Night Vein Anthuriums

Static website built on the GitHub Pages structure of Myomie Baseline Reset, isolated in `nightvein/` on branch `nightvein-anthuriums`. Open index.html or serve this directory with any static web server. No build step or application dependencies.

The source repository’s existing site is preserved. Deploy this directory as a separate GitHub Pages site, or merge this additive directory to publish under /nightvein/ on the existing Pages domain. Merely pushing this branch does not change the existing Pages deployment.

Images: all 28 supplied local photographs and 71 additional Instagram post photographs are represented. The saved Instagram page contained 68 post-image files. Two matched local originals; previously downloaded lower-resolution copies were replaced by the supplied versions. Profile avatars were excluded. Source filenames and available post links are in image-manifest.json. The gallery has 98 images, with the Sharon-and-Pax photo featured separately. The saved page includes post images and reel covers, not every carousel interior or video frame.

Copy follows the owner-provided brief. Individual species and hybrid identities are not guessed. Golden Child, Miss Universe, and Dr. Block labels come from supplied filenames. The grow room description is a personal story, not technical care instructions. Heat supplies warmth; mist supplies moisture.
