# Myomie Baseline Reset

A light, chapter-based web edition of Kelley's *Baseline Reset* guide for Myomie.

The site is intentionally separate from the PPX18 manual repository. It includes searchable chapter navigation, Flip and Scroll reading modes, responsive layouts, original SVG chapter artwork, and links to Myomie's website, contact email, YouTube channel, Spotify, and podcast page.
